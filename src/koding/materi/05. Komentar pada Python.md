# Komentar pada Python

Pada materi ini, peserta didik akan mempelajari pengertian **komentar (comment)**, fungsi komentar, cara penulisan komentar satu baris dan beberapa baris, serta pentingnya komentar dalam membuat program yang mudah dipahami. Materi ini menjadi dasar agar kode yang dibuat lebih rapi, mudah dibaca, dan mudah dipelihara.

---

## Komentar (Comment) pada Python

<img src="/portal-pembelajaran/assets/images/koding/5-komentar-pada-python.webp" alt="Komentar pada Python" class="w-full rounded-lg shadow-md mb-6" loading="lazy">

Komentar (**comment**) adalah bagian dari kode program yang **tidak dieksekusi** atau **tidak dijalankan** oleh Python. Komentar digunakan sebagai **catatan** atau **penjelasan** agar program lebih mudah dibaca, dipahami, dan dipelihara.

Komentar sangat bermanfaat untuk menjelaskan fungsi suatu kode, membantu programmer lain memahami program, mengingatkan programmer saat kembali membuka program, serta menonaktifkan sementara kode ketika melakukan pengujian (*debugging*).

---

## Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta didik diharapkan mampu:

1. Memahami pengertian komentar pada bahasa pemrograman Python.
2. Menjelaskan fungsi komentar dalam sebuah program.
3. Menggunakan komentar satu baris (`#`) dengan benar.
4. Menggunakan komentar beberapa baris (`""" """`).
5. Menulis komentar yang jelas dan mudah dipahami.

---

## Fungsi Komentar

Komentar memiliki beberapa fungsi penting dalam sebuah program, yaitu:

- Menjelaskan fungsi atau tujuan suatu bagian kode.
- Mempermudah programmer lain memahami program.
- Membantu mengingat isi program ketika akan diedit kembali.
- Menonaktifkan sementara kode saat proses *debugging*.

---

## Komentar Satu Baris (`#`)

Komentar satu baris ditulis menggunakan tanda pagar (`#`).

Bentuk penulisannya adalah:

```python
# Ini adalah komentar
```

Contoh:

```python
# Program pertama saya

print("Hello World")
```

Output:

```text
Hello World
```

Semua tulisan setelah tanda `#` pada baris tersebut akan dianggap sebagai komentar sehingga tidak dijalankan oleh Python.

---

## Komentar Beberapa Baris (`""" """`)

Komentar yang lebih panjang dapat ditulis menggunakan tiga tanda kutip dua (`""" """`).

Contoh:

```python
"""
Program ini dibuat
untuk belajar komentar
pada Python.
"""

print("Belajar Python")
```

Output:

```text
Belajar Python
```

> **Catatan:** Penulisan `""" """` sebenarnya merupakan **multi-line string (docstring)**. Namun, cara ini sering digunakan sebagai dokumentasi atau penjelasan program.

---

## Komentar di Samping Kode

Komentar juga dapat ditulis di akhir suatu baris program (*inline comment*).

Contoh:

```python
print("Hello World") # Menampilkan teks Hello World
```

Komentar seperti ini digunakan untuk memberikan penjelasan singkat terhadap satu baris kode.

---

## Contoh Program

```python
# Ini adalah komentar

# Tulisan ini tidak akan dieksekusi

# Komentar dengan tanda pagar
# hanya digunakan
# untuk satu baris

"""
Komentar lebih dari
satu baris menggunakan
tiga tanda kutip dua.
"""

print("Hello World") # Ini juga komentar

#print("Welcome")

# komentar bisa berisi karakter khusus
# !@#$%^&*(),./;'[]\

# mencetak nama
print("Budi")

# mencetak angka
print(123)
```

Output:

```text
Hello World
Budi
123
```

Pada program di atas, Python hanya menjalankan perintah **`print()`**, sedangkan seluruh komentar diabaikan. Oleh karena itu, output yang muncul hanyalah **Hello World**, **Budi**, dan **123**.

---

## Hal-hal yang Perlu Diperhatikan

- Gunakan tanda **`#`** untuk komentar satu baris.
- Gunakan **`""" """`** untuk dokumentasi atau komentar yang lebih panjang.
- Komentar tidak akan dieksekusi oleh Python.
- Tulis komentar yang singkat, jelas, dan sesuai dengan isi program.
- Hindari komentar yang tidak sesuai dengan isi kode karena dapat membingungkan pembaca.

---

## Kesimpulan

Komentar (**comment**) adalah bagian dari program Python yang **tidak dijalankan** oleh interpreter. Komentar digunakan untuk memberikan penjelasan sehingga kode lebih mudah dibaca, dipahami, dan dipelihara. Dalam Python, komentar dapat ditulis menggunakan tanda **`#`** untuk satu baris, sedangkan dokumentasi atau komentar yang lebih panjang dapat menggunakan **`""" """`**. Kebiasaan menulis komentar yang baik akan membuat program lebih rapi, mudah dipahami, dan mudah dikembangkan.
