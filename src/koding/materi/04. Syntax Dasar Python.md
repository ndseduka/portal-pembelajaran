# Syntax Dasar Python

Pada materi ini, peserta didik akan mempelajari pengertian **syntax**, cara menggunakan fungsi **`print()`**, menampilkan teks (String), angka, hasil perhitungan, serta memahami konsep **Case Sensitive** pada bahasa pemrograman Python. Materi ini menjadi dasar sebelum mempelajari variabel, tipe data, dan struktur program Python.

---

## Syntax Dasar Python

<img src="/portal-pembelajaran/assets/images/koding/4-hello-world-python.webp" alt="Hello World Python" class="w-full rounded-lg shadow-md mb-6" loading="lazy">

Syntax (sintaks) adalah aturan atau tata cara penulisan kode program agar dapat dipahami dan dijalankan oleh Python.

Setiap bahasa pemrograman memiliki aturan penulisan yang berbeda-beda. Python dikenal memiliki syntax yang sederhana, mudah dibaca, dan mudah dipelajari sehingga menjadi salah satu bahasa pemrograman yang paling populer bagi pemula.

Apabila syntax ditulis dengan benar, program dapat dijalankan tanpa masalah. Sebaliknya, jika terjadi kesalahan penulisan, Python akan menampilkan **error** sehingga program tidak dapat dijalankan.

## Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta didik diharapkan mampu:

1. Memahami pengertian syntax pada bahasa pemrograman Python.
2. Menggunakan fungsi **`print()`** untuk menampilkan output.
3. Menampilkan data berupa teks (String) dan angka.
4. Menampilkan hasil operasi matematika sederhana menggunakan Python.
5. Memahami konsep **Case Sensitive** pada Python.

---

## Fungsi `print()`

Fungsi **`print()`** digunakan untuk **menampilkan output** ke layar.

Bentuk penulisannya adalah:

```python
print(data)
```

Data yang ingin ditampilkan ditulis di dalam tanda kurung `()`.

Contoh:

```python
print("Hello World")
```

Output:

```text
Hello World
```

Pada contoh di atas:

- `print()` merupakan fungsi untuk menampilkan output.
- `"Hello World"` merupakan data bertipe **String**.
- String harus ditulis di dalam tanda kutip (`"` atau `'`).

---

## Menampilkan Teks (String)

String adalah kumpulan karakter berupa huruf, angka, atau simbol yang dianggap sebagai **teks**.

Contoh:

```python
print("Selamat Belajar Python")
print("SMA Negeri 1 Sandai")
```

Output:

```text
Selamat Belajar Python
SMA Negeri 1 Sandai
```

---

## Menampilkan Angka

Python juga dapat menampilkan data berupa angka tanpa menggunakan tanda kutip.

Contoh:

```python
print(100)
print(2026)
```

Output:

```text
100
2026
```

---

## Menampilkan Hasil Perhitungan

Selain menampilkan teks dan angka, Python juga dapat menghitung operasi matematika secara langsung.

Contoh:

```python
print(10 + 5)
print(20 - 8)
print(6 * 4)
print(12 / 3)
```

Output:

```text
15
12
24
4.0
```

Python akan menghitung terlebih dahulu, kemudian menampilkan hasilnya ke layar.

---

## Python Bersifat Case Sensitive

Python merupakan bahasa pemrograman yang **Case Sensitive**, artinya **huruf besar dan huruf kecil dianggap berbeda**.

Contoh penulisan yang benar:

```python
print("Halo")
```

Output:

```text
Halo
```

Contoh penulisan yang salah:

```python
Print("Halo")
```

atau

```python
PRINT("Halo")
```

Python akan menampilkan **error** karena hanya mengenal fungsi **`print()`** dengan huruf kecil.

Aturan **Case Sensitive** juga berlaku pada nama variabel, fungsi, maupun identifier lainnya.

---

## Hal-hal yang Perlu Diperhatikan

- Gunakan fungsi **`print()`** untuk menampilkan output.
- Teks (String) harus ditulis di dalam tanda kutip.
- Angka tidak perlu menggunakan tanda kutip.
- Perhatikan penggunaan huruf besar dan huruf kecil karena Python bersifat **Case Sensitive**.
- Pastikan tanda kurung dibuka dan ditutup dengan benar.

```python
print("Nama : Andi")

print("Mapel : Informatika")
print(2026)
```

Output:

```text
Nama : Andi
Kelas : XI-A
Mapel : Informatika
2026
```

## Kesimpulan

Syntax adalah aturan penulisan kode pada bahasa pemrograman Python. Salah satu syntax dasar yang paling sering digunakan adalah fungsi **`print()`** untuk menampilkan output ke layar. Python juga membedakan huruf besar dan huruf kecil (**Case Sensitive**), sehingga penulisan syntax harus dilakukan dengan benar agar program dapat dijalankan tanpa menghasilkan error.
