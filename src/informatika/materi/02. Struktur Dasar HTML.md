## Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta didik diharapkan mampu:

1.  Menjelaskan peran HTML dalam menyediakan media untuk desain dan interaktivitas.
2.  Memahami konsep elemen dan tag HTML.
3.  Membedakan tag pembuka dan tag penutup.
4.  Menjelaskan struktur dasar sebuah elemen HTML.

6.  Memahami pengertian elemen kosong (**empty elements**).
7. Mengenal penggunaan elemen `<img>`, `<br>`, dan `<hr>` dalam HTML.

## Analogi HTML, CSS, dan JavaScript
Jika sebuah website diibaratkan sebagai sebuah rumah, maka (Robbins,

2018):

-   ****HTML adalah kerangkanya****
    Menentukan jumlah ruangan, pintu, jendela, dan dinding.

-   ****CSS adalah cat dan dekorasinya****
    Menambahkan warna, pola, ukuran, dan gaya.

-   ****JavaScript adalah peralatannya****
    Menambahkan fungsi seperti membuka pintu secara otomatis atau enyalakan lampu dengan sensor. engan memahami HTML, pengembang dapat membangun kerangka dasar halaman websebelum mempercantik dan memberikan fungsi tambahan menggunakan
teknologi lain seperti CSS dan JavaScript.
Hal ini menjadikan HTML sebagai langkah pertama yang penting dalam perjalanan pengembangan web.

### 1. Elemen Dasar (Tag Pembuka dan Penutup)
Setiap elemen HTML umumnya memiliki struktur dasar yang terdiri dari

****tag pembuka, konten, dan tag penutup****.
Format umum struktur elemen HTML:
``` html
<tag>Konten</tag>
```

#### Penjelasan
****Tag Pembuka****

Terdiri dari nama elemen di dalam tanda kurung sudut, misalnya `<p>`
untuk paragraf.

Contoh:
``` html

<p>

```

****Konten****

Informasi yang ingin ditampilkan di halaman web, seperti teks, gambar,
atau elemen lainnya.

Contoh:
``` html
Ini adalah sebuah paragraf.
```

****Tag Penutup****

Sama seperti tag pembuka tetapi diawali dengan garis miring `/`.
Contoh:

``` html

</p>

```

---

### Contoh Elemen Dasar

``` html
<h1>Selamat Datang</h1>

```

``` html

<p>Ini adalah sebuah paragraf.</p>

```

#### Penjelasan

-   Elemen `<h1>` menampilkan teks sebagai judul besar.

-   Elemen `<p>` menampilkan teks dalam format paragraf.

### Catatan

Tag pembuka dan tag penutup harus digunakan dengan benar untuk
memastikan halaman web ditampilkan sesuai harapan.
Kesalahan seperti tag penutup yang hilang dapat menyebabkan masalah
dalam struktur halaman.
Contoh yang benar:

``` html

<h1>Judul Halaman</h1>

```

Contoh yang tidak benar:

``` html

<h1>Judul Halaman

```

## 2. Elemen Kosong (****Empty Elements****)

### a. Apa Itu Elemen Kosong?

Elemen kosong adalah elemen HTML yang **tidak memiliki konten atau tag
penutup**.
Elemen-elemen ini biasanya digunakan untuk tugas-tugas spesifik,
seperti:
-   menyisipkan gambar;
-   memindahkan baris;
-   menampilkan garis horizontal.
Beberapa contoh elemen kosong adalah:
``` html

<img>

```

``` html

<br>

```

``` html

<hr>

```

---

### b. `<img>`: Untuk Menampilkan Gambar
Elemen `<img>` digunakan untuk menampilkan gambar pada halaman web.

Contoh:

``` html

<img src="gambar.jpg" alt="Deskripsi Gambar">

```

#### Penjelasan

****`src`****

Menentukan lokasi atau nama file gambar.

Contoh:

``` html

src="gambar.jpg"

```

****`alt`****

Memberikan deskripsi alternatif jika gambar tidak dapat dimuat.

Contoh:

``` html

alt="Deskripsi Gambar"

```

### Contoh Struktur Folder

Agar gambar dapat ditampilkan dengan benar, file gambar dapat diletakkan

dalam satu folder dengan file `index.html`.

``` text

website/

│

├── index.html

└── gambar.jpg

```

Kemudian gunakan:

``` html

<img src="gambar.jpg" alt="Deskripsi Gambar">

```

---

### c. `<br>`: Untuk Membuat Baris Baru

Elemen `<br>` digunakan untuk memindahkan teks ke baris berikutnya tanpa

membuat paragraf baru.

Contoh:

``` html

Baris pertama.<br>

Baris kedua.

```

Hasilnya:

``` text

Baris pertama.

Baris kedua.

```

Contoh penggunaan dalam informasi siswa:

``` html

<p>

    Nama: Andi<br>

    Kelas: XII A1<br>

    Mata Pelajaran: Informatika

</p>

```

---

### d. `<hr>`: Untuk Menampilkan Garis Horizontal

Elemen `<hr>` digunakan untuk menampilkan garis horizontal sebagai

pemisah antara bagian-bagian konten.

Contoh:

``` html

<h2>Materi HTML</h2>

<hr>

<p>

    HTML digunakan untuk membangun struktur halaman web.

</p>

```

Garis horizontal dapat membantu memberikan penekanan visual dan

memisahkan satu bagian materi dengan bagian lainnya.

---

### Catatan Penting

Elemen kosong ****tidak memiliki tag penutup**** seperti `</img>` atau

`</br>`.

Contoh yang benar:

``` html

<img src="gambar.jpg" alt="Gambar">

```

``` html

<br>

```

``` html

<hr>

```

Tidak perlu menuliskan:

``` html

</img>

```

atau:

``` html

</br>

```

Elemen kosong sering kali dilengkapi dengan ****atribut**** untuk memberikan

informasi tambahan.

Contohnya:

``` html

<img src="gambar.jpg" alt="Deskripsi Gambar">

```

Pada kode tersebut:

-   `src` merupakan atribut yang menentukan lokasi gambar.

-   `alt` merupakan atribut yang memberikan deskripsi alternatif gambar.

---

## Contoh Gabungan Elemen HTML

Berikut contoh sederhana yang menggabungkan beberapa elemen HTML yang

telah dipelajari:

``` html

<!DOCTYPE html>

<html lang="id">

<head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Dokumen HTML Pertama</title>

</head>

<body>

    <h1>Selamat Datang di Halaman Saya</h1>

    <h2>Belajar HTML</h2>

    <p>

        Ini adalah halaman web pertama yang saya buat menggunakan HTML.

    </p>

    <hr>

    <h2>Data Diri</h2>

    <p>

        Nama: Andi<br>

        Kelas: XII A1<br>

        Mata Pelajaran: Informatika

    </p>

    <h2>Hobi Saya</h2>

    <ul>

        <li>Membaca</li>

        <li>Bermain sepak bola</li>

        <li>Mendengarkan musik</li>

    </ul>

    <h2>Gambar</h2>

    <img src="gambar.jpg" alt="Deskripsi Gambar" width="300">

    <br><br>

    <a href="https\://www.google.com">

        Kunjungi Google

    </a>

</body>

</html>

```

Kode tersebut menunjukkan bahwa berbagai elemen HTML dapat digunakan

secara bersama-sama untuk membangun sebuah halaman web sederhana.

## Kesimpulan

HTML merupakan fondasi utama dalam pengembangan web yang digunakan untuk

menyusun struktur dan konten halaman web.

HTML menggunakan ****elemen dan tag**** untuk menentukan bagaimana konten

ditampilkan dan diproses oleh browser.

Elemen HTML umumnya terdiri dari:

``` text

Tag Pembuka + Konten + Tag Penutup

```

Contoh:

``` html

<p>Ini adalah paragraf.</p>

```

Selain elemen biasa, terdapat ****elemen kosong (****empty elements****)****

seperti:

``` html

<img>

<br>

<hr>

```

Elemen kosong tidak memiliki tag penutup dan digunakan untuk fungsi

tertentu, seperti menampilkan gambar, membuat baris baru, dan

menampilkan garis horizontal.

Dengan memahami HTML, peserta didik memiliki dasar untuk membangun

struktur halaman web sebelum menambahkan desain menggunakan ****CSS**** dan

interaktivitas menggunakan ****JavaScript****.

> **HTML adalah langkah awal untuk membangun sebuah website. Kuasai

> strukturnya terlebih dahulu, kemudian kembangkan tampilannya dengan

> CSS dan fungsinya dengan JavaScript.**
