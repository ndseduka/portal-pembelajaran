**Apa Itu HTML dan Perannya**

HTML adalah fondasi utama dalam pengembangan web, berikut ini peran utama HTML (Network, 2024c):

** 1. Menyusun Struktur Konten**

HTML bertindak sebagai “kerangka” dari halaman web. Setiap elemen dalam HTML, seperti `<h1>` untuk judul atau `<p>` untuk paragraf, memiliki fungsi tertentu untuk menyusun informasi secara terorganisir.

**2. Menghubungkan Konten Secara Global**

Dengan elemen seperti `<a>`, HTML memungkinkan pembuatan tautan yang menghubungkan halaman web di seluruh dunia, menjadikan internet sebuah jaringan informasi yang terhubung.

**3. Menyediakan Media untuk Desain dan Interaktivitas**

HTML menyediakan elemen dasar yang dapat dihias dengan CSS dan diberi interaktivitas menggunakan JavaScript. Dengan demikian, HTML adalah fondasi untuk menciptakan halaman web yang menarik dan fungsional.

**4. Kompatibilitas Universal**

HTML dirancang untuk dapat dibaca oleh semua browser modern, sehingga memastikan bahwa halaman web dapat diakses oleh siapa saja, di mana saja, dan pada perangkat apa pun.

Analogi HTML, jika sebuah website diibaratkan sebagai sebuah rumah, maka (Robbins, 2018):

- HTML adalah kerangkanya: Menentukan jumlah ruangan, pintu, jendela, dan dinding.
- CSS adalah cat dan dekorasinya: Menambahkan warna, pola, dan gaya.
- JavaScript adalah peralatannya: Menambahkan fungsi seperti membuka pintu secara otomatis atau menyalakan lampu dengan sensor.

Dengan memahami HTML, pengembang dapat membangun kerangka dasar halaman web sebelum mempercantik dan memberikan fungsi tambahan menggunakan teknologi lain seperti CSS dan JavaScript. Hal ini menjadikan HTML sebagai langkah pertama yang penting dalam perjalanan pengembangan web.

---

**Elemen dan Tag HTML**

Dalam HTML, elemen dan tag adalah dua komponen penting yang bekerja bersama untuk menyusun dan menampilkan konten di halaman web. Elemen adalah blok bangunan dasar HTML yang merepresentasikan bagian dari halaman, seperti paragraf, gambar, atau tabel. Elemen ini didefinisikan oleh tag yang memberi tahu browser bagaimana cara menampilkan atau memproses elemen tersebut.

**1. Elemen Dasar (Tag Pembuka dan Penutup)**

Setiap elemen HTML memiliki struktur dasar yang terdiri dari tag pembuka, konten, dan tag penutup. Berikut adalah format umum dari struktur elemen HTML:

`<tag>Konten</tag>`

**\*\*Penjelasan:\*\***

- **\*\*Tag Pembuka:\*\*** Terdiri dari nama elemen di dalam tanda kurung sudut, misalnya `<p>` untuk paragraf.
- **\*\*Konten:\*\*** Informasi yang ingin ditampilkan di halaman web, seperti teks, gambar, atau elemen lainnya.
- **\*\*Tag Penutup:\*\*** Sama seperti tag pembuka tetapi diawali dengan garis miring /, misalnya `</p>`.

**\*\*Contoh Elemen Dasar:\*\***

`<h1>Selamat Datang</h1>`

`<p>Ini adalah sebuah paragraf.</p>`

**\*\*Penjelasan:\*\***

- Elemen `<h1>` menampilkan teks sebagai judul besar.
- Elemen `<p>` menampilkan teks dalam format paragraf.

**\*\*Catatan:\*\***

Tag pembuka dan penutup harus digunakan dengan benar untuk memastikan halaman web ditampilkan sesuai harapan. Kesalahan seperti tag penutup yang hilang dapat menyebabkan masalah dalam struktur halaman.

---

**2. Elemen Kosong (Empty Elements)**

**a. Apa Itu Elemen Kosong**

Elemen kosong adalah elemen HTML yang tidak memiliki konten atau tag penutup. Elemen-elemen ini biasanya digunakan untuk tugas-tugas spesifik, seperti menyisipkan gambar, memindahkan baris, atau menampilkan garis horizontal.

**\*\*Contoh Elemen Kosong:\*\***

**\*\*1) `<img>`: Untuk menampilkan gambar.\*\***

`<img src=”gambar.jpg” alt=”Deskripsi Gambar”>`

**\*\*Penjelasan:\*\***

**\*\*2) `src`: Menentukan lokasi file gambar.\*\***

**\*\*3) `alt`: Memberikan deskripsi alternatif jika gambar tidak dapat dimuat.\*\***

**#### b. `<br>`: Untuk membuat baris baru.**

`Baris pertama.<br> baris kedua.`

**#### c. `<hr>`: Untuk menampilkan garis horizontal.**

`<hr>`

**\*\*Catatan:\*\***

Elemen kosong tidak memiliki tag penutup seperti `</img>` atau `</br>`.  

Elemen kosong sering kali dilengkapi dengan atribut untuk memberikan informasi tambahan.

---
**##KESIMPULAN**

HTML merupakan fondasi utama dalam pengembangan web yang digunakan untuk menyusun struktur dan konten halaman web. HTML menggunakan elemen dan tag untuk menentukan bagaimana konten ditampilkan dan diproses oleh browser.
Elemen HTML umumnya terdiri dari tag pembuka, konten, dan tag penutup. Selain itu, terdapat elemen kosong (empty elements) seperti <'img'>, <'br'>, dan <'hr'>yang tidak memiliki tag penutup dan digunakan untuk fungsi tertentu. Dengan memahami HTML, peserta didik memiliki dasar untuk membangun struktur halaman web sebelum menambahkan desain menggunakan CSS dan interaktivitas menggunakan JavaScript.
