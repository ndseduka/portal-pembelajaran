## Pengenalan Python
<img src="/portal-pembelajaran/assets/images/koding/1-pendahuluan-python.webp">

[Python](https://www.python.org) adalah bahasa pemrograman interpretatif multiguna. Tidak seperti bahasa lain yang susah untuk dibaca dan dipahami, python lebih menekankan pada keterbacaan kode agar lebih mudah untuk memahami sintaks. Hal ini membuat Python sangat mudah dipelajari baik untuk pemula maupun untuk yang sudah menguasai bahasa pemrograman lain.

Bahasa ini muncul pertama kali pada tahun 1991, dirancang oleh seorang bernama [Guido van Rossum](https://id.wikipedia.org/wiki/Guido_van_Rossum). Sampai saat ini Python masih dikembangkan oleh [Python Software Foundation](https://www.python.org/psf/). Bahasa Python mendukung hampir semua sistem operasi, bahkan untuk sistem operasi Linux, hampir semua distronya sudah menyertakan Python di dalamnya.
 
Python telah menjadi salah satu bahasa pemrograman paling populer di dunia, terutama karena perannya yang dominan di bidang:

- **Kecerdasan Buatan (AI) dan Machine Learning** - Library seperti TensorFlow, PyTorch, dan scikit-learn menjadikan Python pilihan utama untuk pengembangan AI.
- **Data Science dan Analisis Data** - Pandas, NumPy, dan Matplotlib adalah tools standar industri.
- **Pengembangan Web** - Framework seperti Django, Flask, dan FastAPI.
- **Otomasi dan Scripting** - Mengotomasi tugas-tugas repetitif dengan mudah.
- **Internet of Things (IoT)** - Digunakan di Raspberry Pi dan perangkat embedded.

Versi terbaru Python saat ini adalah **Python 3.13** dengan berbagai fitur modern seperti pattern matching, improved error messages, dan performa yang lebih baik.

Dengan kode yang simpel dan mudah diimplementasikan, seorang programmer dapat lebih mengutamakan pengembangan aplikasi yang dibuat, bukan malah sibuk mencari syntax error.

```python
print("Python sangat simpel")
```

Hanya dengan menuliskan kode print seperti yang diatas, anda sudah bisa mencetak apapun yang anda inginkan di dalam tanda kurung `()`. Dibagian akhir kode pun, anda tidak harus mengakhirnya dengan tanda semicolon `;`

## Mengapa Python

Python adalah bahasa pemrograman yang mudah dipelajari, memiliki sintaks yang sederhana, serta didukung oleh banyak modul siap pakai. Python juga bersifat open source, gratis, dan dapat dijalankan di berbagai sistem operasi seperti Windows, Linux, dan macOS.

---

## Fitur Utama Python

- Memiliki banyak library siap digunakan.
- Sintaks sederhana dan mudah dibaca.
- Mendukung pemrograman berorientasi objek (OOP).
- Mengelola memori secara otomatis (garbage collection).
- Mudah dikembangkan dengan modul Python maupun C/C++.
- Dapat berjalan di berbagai sistem operasi (multiplatform).

---

## Kelebihan Python

- Mudah dipelajari dan digunakan.
- Penulisan program lebih singkat dan sederhana.
- Tidak memerlukan proses kompilasi yang rumit.
- Memiliki banyak library untuk berbagai kebutuhan.
- Mendukung pemrograman berorientasi objek (OOP).
- Cocok untuk pengembangan web, aplikasi, AI, data science, dan otomatisasi.

---

## Kekurangan Python

- Kecepatan eksekusi lebih lambat dibandingkan C atau C++.
- Kurang cocok untuk aplikasi yang membutuhkan performa sangat tinggi.
- Tidak umum digunakan untuk membuat sistem operasi atau perangkat lunak tingkat rendah.
- Terkadang perlu dipadukan dengan bahasa lain untuk meningkatkan performa.

---

## Kesimpulan

Python menjadi salah satu bahasa pemrograman paling populer karena mudah dipelajari, fleksibel, dan memiliki banyak library yang mendukung berbagai bidang pengembangan aplikasi. Meskipun lebih lambat dibandingkan bahasa seperti C atau C++, Python tetap menjadi pilihan utama bagi pemula maupun profesional.
