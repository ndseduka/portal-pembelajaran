# Tag, Elemen, dan Atribut dalam HTML

Tag, elemen, dan atribut merupakan tiga bagian penting dalam HTML. Ketiganya digunakan untuk menyusun struktur halaman web dan memberikan informasi kepada browser mengenai bagaimana sebuah dokumen HTML harus dibaca.

Pada materi ini, peserta didik akan mempelajari pengertian **tag**, **elemen**, dan **atribut**, perbedaan ketiganya, cara menulis tag HTML dengan benar, jenis-jenis atribut, serta aturan dasar penulisan atribut.

---

## Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta didik diharapkan mampu:

1. Menjelaskan pengertian tag pada HTML.
2. Menjelaskan pengertian elemen pada HTML.
3. Menjelaskan pengertian atribut pada HTML.
4. Membedakan tag, elemen, dan atribut.
5. Menulis tag HTML dengan benar.
6. Memahami tag pembuka dan tag penutup.
7. Memahami konsep elemen bersarang atau *nested element*.
8. Menggunakan atribut pada elemen HTML.
9. Mengenal atribut global, atribut event, dan atribut khusus.
10. Menulis atribut HTML dengan format yang benar.

---

## Apa Itu Tag?

<img src="/portal-pembelajaran/assets/images/koding/03-tag-elemen-atribut-dalam-html.webp" alt="Tag, Elemen, dan Atribut HTML" class="w-full rounded-lg shadow-md mb-6" loading="lazy">

Tag adalah penanda awalan dan akhiran dari sebuah elemen HTML. Tag ditulis menggunakan tanda kurung sudut (`< >`) dan di dalamnya terdapat nama tag.

Contoh:

```html
<p>
<a>
<body>
<head>
```

Setiap tag memiliki fungsi tertentu. Ada tag yang digunakan untuk membuat paragraf, heading, tautan, gambar, bagian dokumen, dan berbagai kebutuhan lainnya.

Contoh sederhana:

```html
<p>Belajar HTML</p>
```

Pada contoh tersebut terdapat tag pembuka:

```html
<p>
```

dan tag penutup:

```html
</p>
```

Isi yang berada di antara kedua tag tersebut adalah:

```text
Belajar HTML
```

---

## Tag Pembuka dan Tag Penutup

Sebagian besar elemen HTML memiliki tag pembuka dan tag penutup.

Tag pembuka ditulis seperti:

```html
<p>
```

Sedangkan tag penutup menggunakan tanda garis miring (`/`) sebelum nama tag:

```html
</p>
```

Jika digabungkan:

```html
<p>Belajar HTML</p>
```

Strukturnya dapat dipahami sebagai:

```text
<p>           → tag pembuka
Belajar HTML  → isi
</p>          → tag penutup
```

---

## Contoh Tag HTML Dasar

Beberapa tag HTML dasar yang perlu diketahui antara lain:

| Tag | Fungsi |
|---|---|
| `<!DOCTYPE html>` | Mendeklarasikan tipe dokumen HTML |
| `<html>` | Menjadi elemen utama dokumen HTML |
| `<head>` | Menyimpan informasi atau metadata dokumen |
| `<title>` | Menentukan judul dokumen |
| `<body>` | Menampung isi utama halaman web |
| `<h1>` sampai `<h6>` | Membuat heading |
| `<p>` | Membuat paragraf |
| `<!-- -->` | Membuat komentar |

Tidak semua tag HTML harus dihafalkan sekaligus. Peserta didik sebaiknya memahami fungsi tag-tag dasar terlebih dahulu dan mempelajari tag lainnya secara bertahap.

---

## Tag yang Tidak Memiliki Pasangan Penutup

Tidak semua tag HTML memiliki tag penutup seperti `<p>` dan `</p>`.

Beberapa elemen HTML tidak memerlukan pasangan tag penutup.

Contoh:

```html
<img src="gambar.jpg">
```

Tag `<img>` digunakan untuk menampilkan gambar.

Contoh lainnya:

```html
<br>
```

Tag `<br>` digunakan untuk membuat perpindahan baris.

---

## Tag Wajib dalam Struktur HTML

Sebuah dokumen HTML dasar umumnya memiliki struktur utama seperti berikut:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Belajar HTML</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Saya sedang belajar HTML.</p>
</body>
</html>
```

Beberapa bagian penting dalam struktur tersebut adalah:

```html
<!DOCTYPE html>
```

Digunakan untuk deklarasi tipe dokumen.

```html
<html>
```

Merupakan elemen utama yang membungkus dokumen HTML.

```html
<head>
```

Digunakan untuk bagian kepala dokumen.

```html
<title>
```

Digunakan untuk menentukan judul halaman.

```html
<body>
```

Digunakan untuk menampung isi halaman web yang ditampilkan kepada pengguna.

---

## Menggunakan Huruf Kecil pada Nama Tag

Dalam penulisan HTML, sebaiknya nama tag ditulis menggunakan huruf kecil agar kode lebih rapi, konsisten, dan mudah dibaca.

Contoh yang disarankan:

```html
<body>
<p>Belajar tentang HTML</p>
</body>
```

Dibandingkan:

```html
<BODY>
<P>Belajar tentang HTML</P>
</BODY>
```

Penggunaan huruf kecil merupakan kebiasaan penulisan yang baik.

---

## Menutup Tag dengan Benar

Ketika elemen HTML ditulis bertumpuk, tag harus ditutup dengan urutan yang benar.

Prinsipnya adalah:

> Tag yang pertama dibuka harus ditutup paling terakhir.

Contoh:

```html
<i><b><u>Belajar HTML</u></b></i>
```

Urutannya:

```text
<i> dibuka terlebih dahulu
<b> dibuka
<u> dibuka
<u> ditutup terlebih dahulu
<b> ditutup
<i> ditutup terakhir
```

---

## Nested Element

Elemen HTML dapat berada di dalam elemen HTML lainnya. Kondisi ini disebut **nested element** atau elemen bersarang.

Contoh:

```html
<p>
    Saya sedang belajar
    <b>HTML</b>
</p>
```

Pada contoh tersebut, elemen `<b>` berada di dalam elemen `<p>`.

Contoh lainnya:

```html
<div>
    <h1>Belajar HTML</h1>
    <p>HTML digunakan untuk membuat struktur halaman web.</p>
</div>
```

Elemen `<h1>` dan `<p>` berada di dalam elemen `<div>`.

---

## Apa Itu Elemen?

Elemen dalam HTML adalah komponen yang menyusun dokumen HTML.

Sebuah elemen dapat terdiri dari:

- Tag pembuka.
- Isi elemen.
- Tag penutup.
- Atribut, jika diperlukan.

Contoh:

```html
<p>Halo Dunia!</p>
```

Pada contoh tersebut:

```text
<p>           → tag pembuka
Halo Dunia!   → isi elemen
</p>          → tag penutup
```

Keseluruhan:

```html
<p>Halo Dunia!</p>
```

disebut sebagai sebuah **elemen HTML**.

---

## Contoh Elemen dengan Atribut

Elemen dapat memiliki atribut sebagai informasi tambahan.

Contoh:

```html
<p align="center">Hello World!</p>
```

Pada contoh tersebut:

- `<p>` adalah tag.
- `align="center"` adalah atribut.
- `Hello World!` adalah isi.
- Keseluruhan kode merupakan elemen.

Secara sederhana:

```text
Tag       : <p>
Atribut   : align="center"
Isi       : Hello World!
Elemen    : keseluruhan bagian tersebut
```

---

## Apa Itu Atribut?

Atribut adalah informasi tambahan yang ditambahkan pada tag pembuka sebuah elemen HTML.

Atribut digunakan untuk memberikan keterangan atau mengatur karakteristik tertentu dari sebuah elemen.

Contoh:

```html
<a href="https://contoh.com">Kunjungi Website</a>
```

Pada contoh tersebut:

```html
href="https://contoh.com"
```

merupakan atribut.

Atribut `href` menentukan tujuan tautan yang dibuat oleh elemen `<a>`.

---

## Struktur Atribut

Bentuk umum penulisan atribut adalah:

```html
nama-atribut="nilai"
```

Contoh:

```html
href="https://contoh.com"
```

Bagian:

```text
href
```

merupakan nama atribut.

Sedangkan:

```text
"https://contoh.com"
```

merupakan nilai atribut.

Contoh lain:

```html
<img src="gambar.jpg" width="300" height="200">
```

Pada kode tersebut terdapat beberapa atribut:

```text
src    → menentukan sumber gambar
width  → menentukan lebar
height → menentukan tinggi
```

---

## Atribut pada Tag `<a>`

Tag `<a>` digunakan untuk membuat tautan atau link.

Contoh:

```html
<a href="https://contoh.com">Buka Website</a>
```

Atribut `href` menentukan halaman tujuan ketika tautan diklik.

---

## Atribut pada Tag `<img>`

Tag `<img>` digunakan untuk menampilkan gambar.

Contoh:

```html
<img src="gambar.jpg" width="300" height="200">
```

Terdapat tiga atribut pada contoh tersebut:

`src` digunakan untuk menentukan sumber atau lokasi gambar.

`width` digunakan untuk menentukan lebar gambar.

`height` digunakan untuk menentukan tinggi gambar.

---

## Satu Elemen Dapat Memiliki Banyak Atribut

Contoh:

```html
<img src="gambar.jpg" width="300" height="200" alt="Foto sekolah">
```

Pada contoh tersebut terdapat beberapa atribut:

```text
src
width
height
alt
```

Setiap atribut memberikan informasi yang berbeda kepada elemen `<img>`.

---

## Jenis-Jenis Atribut HTML

Atribut yang perlu dikenal pada pembelajaran dasar HTML dapat dikelompokkan menjadi:

1. Atribut global.
2. Atribut event.
3. Atribut khusus.

---

## Atribut Global

Atribut global adalah atribut yang dapat digunakan pada berbagai elemen HTML.

Beberapa contoh atribut global:

| Atribut | Fungsi |
|---|---|
| `class` | Menentukan class yang dapat digunakan oleh CSS |
| `id` | Memberikan identitas pada elemen |
| `style` | Memberikan CSS secara langsung pada elemen |
| `title` | Memberikan informasi tambahan |
| `lang` | Menentukan bahasa |
| `hidden` | Menyembunyikan elemen |
| `contenteditable` | Menentukan apakah isi elemen dapat diedit |
| `draggable` | Menentukan apakah elemen dapat dipindahkan dengan drag |
| `tabindex` | Mengatur urutan fokus saat menggunakan tombol Tab |
| `dir` | Menentukan arah teks |
| `spellcheck` | Menentukan pemeriksaan ejaan |
| `translate` | Menentukan apakah isi dapat diterjemahkan |
| `data-*` | Menyimpan data tambahan pada elemen |

Contoh:

```html
<p id="judul" class="utama">Belajar HTML</p>
```

Pada contoh tersebut terdapat atribut `id` dan `class`.

---

## Atribut `id`

Atribut `id` digunakan untuk memberikan identitas pada sebuah elemen.

Contoh:

```html
<h1 id="judul">Belajar HTML</h1>
```

Elemen tersebut memiliki identitas `judul`.

Atribut `id` sering digunakan ketika elemen perlu dikenali secara khusus, misalnya oleh CSS atau JavaScript.

---

## Atribut `class`

Atribut `class` digunakan untuk memberikan nama kelompok atau kelas kepada elemen.

Contoh:

```html
<p class="paragraf">Belajar HTML</p>
<p class="paragraf">Belajar CSS</p>
```

Kedua elemen tersebut memiliki `class` yang sama.

Class banyak digunakan bersama CSS untuk memberikan tampilan tertentu pada beberapa elemen.

---

## Atribut `style`

Atribut `style` digunakan untuk menuliskan CSS langsung pada sebuah elemen.

Contoh:

```html
<p style="color: blue;">Belajar HTML</p>
```

Penggunaan CSS langsung pada atribut `style` disebut **inline CSS**.

---

## Atribut `title`

Atribut `title` dapat digunakan untuk memberikan informasi tambahan pada sebuah elemen.

Contoh:

```html
<p title="Materi dasar HTML">Belajar HTML</p>
```

Atribut tersebut memberikan keterangan tambahan mengenai elemen.

---

## Atribut Event

Atribut event digunakan untuk menentukan tindakan ketika suatu peristiwa terjadi pada elemen.

Atribut event banyak digunakan bersama JavaScript.

Contoh:

```html
<button onclick="alert('Halo!')">Klik Saya</button>
```

Pada contoh tersebut, `onclick` merupakan event yang dijalankan ketika tombol diklik.

Beberapa contoh event:

| Atribut | Kapan terjadi |
|---|---|
| `onclick` | Ketika elemen diklik |
| `onload` | Ketika proses pemuatan selesai |
| `onerror` | Ketika terjadi kesalahan |
| `onchange` | Ketika nilai elemen berubah |
| `oninput` | Ketika pengguna memasukkan data |
| `onresize` | Ketika ukuran jendela berubah |
| `ononline` | Ketika koneksi online tersedia |
| `onoffline` | Ketika browser mendeteksi kondisi offline |

---

## Atribut Khusus

Atribut khusus adalah atribut yang digunakan oleh elemen tertentu dan tidak selalu dapat digunakan pada semua elemen.

Contoh:

| Atribut | Contoh elemen |
|---|---|
| `src` | `<img>`, `<audio>`, `<iframe>`, dan lainnya |
| `href` | `<a>`, `<link>` |
| `action` | `<form>` |
| `autoplay` | `<audio>`, `<video>` |

Contoh penggunaan `href`:

```html
<a href="halaman.html">Halaman Berikutnya</a>
```

Contoh penggunaan `src`:

```html
<img src="gambar.jpg">
```

---

## Cara Menulis Atribut yang Benar

Atribut ditulis di dalam tag pembuka.

Format dasar:

```html
<nama-tag nama-atribut="nilai">
```

Contoh:

```html
<p class="teks">Belajar HTML</p>
```

Pada contoh tersebut:

```text
<p>            → tag
class="teks"   → atribut
Belajar HTML   → isi
```

---

## Gunakan Huruf Kecil pada Atribut

Sebaiknya nama atribut ditulis menggunakan huruf kecil agar kode lebih konsisten dan mudah dibaca.

Contoh:

```html
<p align="center">Belajar HTML</p>
```

Penulisan:

```html
<p ALIGN="CENTER">Belajar HTML</p>
```

sebaiknya dihindari untuk menjaga konsistensi kode.

---

## Gunakan Tanda Petik pada Nilai Atribut

Nilai atribut yang berupa teks sebaiknya ditulis menggunakan tanda petik.

Contoh:

```html
<h1 title="Tutorial HTML untuk Pemula">Belajar HTML</h1>
```

Tanda petik dapat menggunakan petik ganda:

```html
<p title="Belajar HTML">Paragraf</p>
```

atau petik tunggal:

```html
<p title='Belajar HTML'>Paragraf</p>
```

---

## Mengapa Nilai Atribut Perlu Ditulis dengan Petik?

Perhatikan:

```html
<h1 title="Tutorial HTML untuk Pemula">Belajar HTML</h1>
```

Nilai atribut `title` terdiri dari beberapa kata.

Tanda petik membantu browser mengenali seluruh teks tersebut sebagai satu nilai atribut.

Karena itu, penggunaan tanda petik merupakan kebiasaan penulisan yang baik untuk nilai atribut berbentuk teks.

---

## Atribut Boolean

Beberapa atribut HTML bersifat boolean, yaitu atribut yang menunjukkan ada atau tidaknya suatu kondisi.

Contoh:

```html
<input type="text" required>
```

Atribut `required` menunjukkan bahwa input tersebut wajib diisi.

Atribut boolean dapat ditulis cukup dengan nama atributnya.

---

## Penggunaan Spasi pada Atribut

Spasi digunakan untuk memisahkan satu atribut dengan atribut lainnya.

Contoh:

```html
<img class="lazyload" data-src="gambar.jpg" src="placeholder.jpg">
```

Pada contoh tersebut terdapat tiga atribut:

```text
class="lazyload"
data-src="gambar.jpg"
src="placeholder.jpg"
```

Spasi memisahkan atribut yang satu dengan atribut lainnya.

Jika sebuah nama atribut terdiri dari beberapa bagian, penamaannya tidak menggunakan spasi.

Contoh:

```html
data-src="gambar.jpg"
```

bukan:

```html
data src="gambar.jpg"
```

---

## Membaca Struktur HTML

Perhatikan kode berikut:

```html
<a href="https://contoh.com" class="tautan">
    Kunjungi Website
</a>
```

Kita dapat mengidentifikasinya sebagai berikut:

```text
<a>                  → tag
href="..."           → atribut
class="tautan"       → atribut
Kunjungi Website     → isi
<a> ... </a>         → elemen
```

Dengan memahami pembagian tersebut, peserta didik akan lebih mudah membaca kode HTML.

---

## Perbedaan Tag, Elemen, dan Atribut

Perhatikan kode berikut:

```html
<p class="teks">Belajar HTML</p>
```

### Tag

```html
<p>
</p>
```

Tag merupakan penanda pembuka dan penutup elemen.

### Atribut

```html
class="teks"
```

Atribut memberikan informasi tambahan kepada elemen.

### Isi

```text
Belajar HTML
```

Isi merupakan konten yang berada di dalam elemen.

### Elemen

```html
<p class="teks">Belajar HTML</p>
```

Keseluruhan struktur tersebut merupakan sebuah elemen HTML.

---

## Perbandingan Tag, Elemen, dan Atribut

| Bagian | Pengertian | Contoh |
|---|---|---|
| Tag | Penanda elemen | `<p>` |
| Atribut | Informasi tambahan | `class="teks"` |
| Isi | Konten elemen | `Belajar HTML` |
| Elemen | Keseluruhan struktur | `<p class="teks">Belajar HTML</p>` |

Cara mudah mengingat:

```text
TAG      → penanda
ATRIBUT  → informasi tambahan
ISI      → konten
ELEMEN   → keseluruhan bagian
```

## Contoh Program HTML Sederhana

Berikut contoh dokumen HTML yang menggunakan tag, elemen, dan atribut:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Belajar HTML</title>
</head>
<body>

    <h1 class="judul">Belajar HTML</h1>

    <p>
        HTML digunakan untuk membuat struktur halaman web.
    </p>

    <a href="https://contoh.com">
        Kunjungi Website
    </a>

</body>
</html>
```

Pada program tersebut terdapat berbagai tag:

```text
<!DOCTYPE html>
<html>
<head>
<title>
<body>
<h1>
<p>
<a>
```

Terdapat pula atribut:

```html
class="judul"
href="https://contoh.com"
```

## Latihan Praktik

Buat sebuah halaman HTML sederhana dengan ketentuan:

1. Memiliki `<!DOCTYPE html>`.
2. Memiliki `<html>`, `<head>`, dan `<body>`.
3. Memiliki judul halaman menggunakan `<title>`.
4. Memiliki heading menggunakan `<h1>`.
5. Memiliki minimal dua paragraf.
6. Memiliki satu tautan menggunakan `<a>`.
7. Memiliki minimal dua atribut.
8. Menggunakan penulisan tag dengan huruf kecil.
9. Menutup tag dengan urutan yang benar.

Contoh:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Profil Siswa</title>
</head>
<body>

    <h1 id="judul">Profil Siswa</h1>

    <p class="informasi">
        Nama saya adalah Budi.
    </p>

    <p>
        Saya sedang belajar HTML.
    </p>

    <a href="https://contoh.com">
        Kunjungi Website
    </a>

</body>
</html>
```

## Hal-hal yang Perlu Diperhatikan

Tag merupakan penanda yang digunakan untuk membentuk elemen HTML.

Sebagian besar tag memiliki tag pembuka dan tag penutup.

Tag penutup menggunakan tanda garis miring (`/`).

Tidak semua elemen HTML memiliki pasangan tag penutup.

Elemen merupakan komponen yang menyusun dokumen HTML.

Elemen dapat memiliki elemen lain di dalamnya atau disebut *nested element*.

Atribut memberikan informasi tambahan pada elemen.

Atribut ditulis di dalam tag pembuka.

Sebuah elemen dapat memiliki lebih dari satu atribut.

Atribut dapat berupa atribut global, atribut event, atau atribut khusus.

Nilai atribut berbentuk teks sebaiknya ditulis menggunakan tanda petik.

Spasi digunakan untuk memisahkan atribut yang satu dengan atribut lainnya.

Nama tag dan atribut sebaiknya ditulis dengan huruf kecil agar kode lebih konsisten dan mudah dibaca.

Tag yang dibuka lebih dahulu harus ditutup setelah tag yang berada di dalamnya.

---

## Kesimpulan

Tag, elemen, dan atribut merupakan bagian penting dalam HTML.

**Tag** digunakan sebagai penanda pembuka dan penutup sebuah elemen.

**Elemen** merupakan komponen yang menyusun dokumen HTML dan dapat terdiri dari tag pembuka, isi, tag penutup, serta atribut.

**Atribut** merupakan informasi tambahan yang ditambahkan pada tag pembuka untuk memberikan keterangan atau mengatur karakteristik tertentu dari sebuah elemen.

Contoh:

```html
<p class="teks">Belajar HTML</p>
```

Pada kode tersebut:

```text
<p>              → tag
class="teks"     → atribut
Belajar HTML     → isi
keseluruhan      → elemen
```

Pemahaman tentang tag, elemen, dan atribut merupakan dasar penting sebelum mempelajari berbagai tag HTML lainnya, membuat struktur halaman web, menggunakan CSS, dan mempelajari JavaScript.
